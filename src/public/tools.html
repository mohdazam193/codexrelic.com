What is an ASP.NET Machine Key?

            

              The <machineKey> element in ASP.NET web.config specifies the algorithms and cryptographic keys used for encryption, decryption, and hash validation of Forms Authentication tickets, ViewState data, and anti-CSRF tokens.
            

            
Why Static Keys in Web Farms / Kubernetes?

            

              By default, IIS sets keys to AutoGenerate. In a load-balanced cluster (AWS ALB, Azure App Service, Kubernetes, or IIS Web Farm), different servers generate differing random keys. A user authenticated on Server A will receive an encryption error when routed to Server B unless all nodes share identical, synchronized static machine keys in web.config.
